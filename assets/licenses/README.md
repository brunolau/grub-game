# Licences of the third-party assets in this folder tree

One text file per source pack. Each file names the author, the source URL, the licence, what the game uses from the pack, the exact licence wording captured from the source page on the download date, and the author's own licence file where one was shipped.
`cc0_1.0_legal_code.txt` is the full Creative Commons Zero 1.0 legal code that the CC0 packs refer to.
